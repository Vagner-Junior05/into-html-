Formulários HTML

O que são Formulários no HTML?

Os formulários são uma das partes mais importantes do HTML pois ajudam a introduzir uma ideia diferente.

O usuário deixa de apenas consumir conteúdo e passa a fornecer dados para o sistema.

Um formulário, de forma resumida, é uma área da página destinada à coleta de informações.

Exemplos de uso:

  • Login
  • Cadastro
  • Contato
  • Pesquisa
  • Comentários
  • Endereço
  • Inscrições em Newsletter

Criando um formulário básico

  • <label>: Representa um rótulo/etiqueta para um campo. É um recurso fundamental para a acessibilidade.
  • for: Conecta o label ao campo através do id do input.
  • id: Identifica de forma única um elemento dentro da página.
  • type: Define o tipo de input apresentado ao usuário com base no dado que queremos coletar.

Resumo dos elementos e atributos

  • <form>: Agrupa os campos que fazem parte de um formulário.
  • <label>: É o rótulo que informa ao usuário o que deve ser preenchido.
  • for: Conecta o label ao campo que possui o id correspondente.
  • <input>: Cria um campo para entrada de dados.
  • type: Define o tipo de dado que será recebido pelo input.
  • id: Identifica o elemento de forma única na página.
  • name: Identifica o dado quando as informações do formulário são enviadas.
  • placeholder: Mostra uma dica ou exemplo dentro do campo.
  • required: Torna o preenchimento do campo obrigatório.
  • maxlength: Define a quantidade máxima de caracteres permitidos.
  • min: Define o menor valor permitido.
  • max: Define o maior valor permitido.
  • <textarea>: Cria uma área para textos maiores.
  • cols: Define aproximadamente a largura visível do textarea.
  • rows: Define a quantidade de linhas visíveis do textarea.
  • <fieldset>: Agrupa campos relacionados.
  • <legend>: Cria o título/legenda de um fieldset.
  • <button>: Cria um botão dentro do formulário.

Principais tipos de input

  • type="text": Nome, empresa, endereço, CPF, CNPJ e textos em geral.
  • type="email": Endereço de e-mail.
  • type="password": Senhas.
  • type="tel": Telefone ou celular.
  • type="number": Valores numéricos.
  • type="date": Datas.
  • type="checkbox": Caixa de seleção.
