Conhecendo o <details>

O que é o <details>?

O <details> representa um conteúdo que o usuário pode abrir e fechar.

O que é HTML?

HTML é a linguagem de marcação usada para estruturar páginas da web.

Quais são as linguagens da WEB??

As principai linguagens são HTML , CSS e JavaScript.

Sobre as linguagens

  • HTML : Linguagem responsável pela estrutura de página web.
  • CSS : Linguagem responsável pela estilização de página web.
  • JavaScript : Linguagem responsável pela interatividade de página web.
