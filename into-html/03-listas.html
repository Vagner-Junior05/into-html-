O que são listas no HTML?

Uma lista é uma sequência de itens relacionados entre si.

No HTML, existem principalmente três tipos de listas: listas não ordenadas, listas ordenadas, e listas de descrição.

Lista não ordenada (ul)

Uma lista não ordenada é usada quando a ordem dos elementos/itens não importa.

  • Arroz
  • Feijão
  • Macarrão
  • Carne
  • Café

Lista ordenada (ol)

Usamos uma lista ordenada quando os itens possuem um sequência, uma classificação ou uma ordem que precisa ser respeitada.

  1. Ferver a água
  2. Colocar o café no filtro
  3. Despejar a água lentamente
  4. Servir o Café

Lista de descrição (dl)

Usamos uma lista de descrição quando precisamos descrever algum termo.

Para criarmos essa lista, utilizamos três elementos:

  • dl (description list) : Representa a lista de descriçãp.
  • dt(description term): Representa o termo.
  • dd(data description): Representa a descrição do termo.
